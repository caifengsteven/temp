# 曲率半径超级趋势指标 - 实现说明

## 概述

本项目实现了基于曲率动力学的超级趋势指标，该指标通过半径加速度函数来模拟市场的自然抛物线运动，而不是简单的线性ATR包络线。

## 核心文件

### 1. `curved_radius_supertrend.py` - 核心实现

这是主要的指标实现文件，包含 `CurvedRadiusSupertrend` 类。

**主要组件：**

#### a) ATR计算 (`calculate_atr`)
- 计算真实波动范围（True Range）
- 使用简单移动平均计算ATR
- 设置 `min_periods=1` 避免初始NaN值

#### b) 基础超级趋势 (`calculate_basic_supertrend`)
- 计算上下轨道：`HL平均 ± (ATR × 乘数)`
- 实现轨道持续逻辑
- 通过价格交叉确定趋势方向

#### c) 曲率加速引擎 (`apply_curvature_acceleration`)
这是核心创新部分：

```python
# 二次加速因子
acceleration_factor = radius_strength × (bars_in_trend)² / 100

# 基于ATR的曲率位移
curve_displacement = acceleration_factor × ATR
```

**上升趋势：**
- 下轨向上弯曲（远离价格）
- 上轨也弯曲但幅度较小

**下降趋势：**
- 上轨向下弯曲（远离价格）
- 下轨也弯曲但幅度较小

#### d) 自适应平滑 (`apply_smoothing`)
- 使用SMA平滑曲线
- 减少噪音同时保持响应性

### 2. `visualize_indicator.py` - 可视化工具

提供全面的可视化功能：

- **参数对比**：并排比较6种不同配置
- **趋势标记**：用蓝色圆圈标记趋势变化点
- **颜色编码**：绿色表示上升趋势，红色表示下降趋势
- **统计分析**：全面的趋势统计信息

### 3. `test_indicator.py` - 测试套件

包含5个测试：
1. 基础计算测试
2. 参数变化测试

```python
import numpy as np

# 准备OHLC数据
high = np.array([...])

    atr_period=10,          # ATR周期

print(result['trend_line'].iloc[-1])   # 当前趋势线值
```

- `curved_lower`：下轨曲线
- `direction`：趋势方向（1=上升，-1=下降）

## 理论基础

### 1. 曲率半径概念

标准超级趋势使用线性ATR包络线，但市场不会线性扩张或收缩。趋势速度通常以非线性弧线加速和减速。

### 2. 加速度模型

通过嵌入基于半径的加速度函数，指标对自然市场行为进行建模：

```
位移 = 0.5 × radius_strength × t² × ATR
```

其中：
- `t` = 趋势中的柱数
- `radius_strength` = 曲率强度参数
- `ATR` = 平均真实范围（波动率度量）

### 3. 优势

✅ **消除滞后**：标准超级趋势的典型滞后被消除  
✅ **流畅运动**：反映实际趋势几何形状的流体定向运动  
✅ **预测能力**：通过加速度建模预测而不仅仅是反应  
✅ **自适应性**：通过半径强度参数适应不同时间框架  

## 解读指标

### 上升趋势阶段
- 轨道随着加速度增加向上弯曲
- 反映市场方向速度的增长
- 曲率越陡，信念越强

### 下降趋势阶段
- 轨道以镜像加速模式向下弯曲
- 表明持续看跌势头
- 加速度随时间复合

### 趋势变化点
- 方向翻转并形成新的锚点
- 曲线重置 - 提供结构反转的干净、早期视觉确认
- 在可视化中用蓝色圆圈标记

### 参数相互作用

**较低的 `radius_strength`（0.1-0.3）：**
- 更紧密、更具反应性的曲线
- 适合剥头皮或短时间框架
- 更频繁的趋势变化

**较高的 `radius_strength`（1.0-2.0）：**
- 宽阔的弧线
- 针对波段或趋势分析优化
- 更少但更重要的趋势变化

**平滑度（1-10）：**
- 较低值：更具响应性，更多噪音
- 较高值：更平滑的曲线，轻微滞后

## 高级用法

### 生成交易信号

```python
def generate_signals(result, close):
    signals = []
    for i in range(1, len(result)):
        # 从下降趋势变为上升趋势 = 买入信号
        if result['direction'].iloc[i] == 1 and result['direction'].iloc[i-1] == -1:
            signals.append(('BUY', i, close[i]))
        # 从上升趋势变为下降趋势 = 卖出信号
        elif result['direction'].iloc[i] == -1 and result['direction'].iloc[i-1] == 1:
            signals.append(('SELL', i, close[i]))
    return signals
```

### 实时数据集成

```python
def update_with_new_bar(indicator, historical_data, new_bar):
    # 将新柱添加到历史数据
    updated_high = np.append(historical_data['high'], new_bar['high'])
    updated_low = np.append(historical_data['low'], new_bar['low'])
    updated_close = np.append(historical_data['close'], new_bar['close'])
    
    # 重新计算指标
    result = indicator.calculate(updated_high, updated_low, updated_close)
    
    return result.iloc[-1]  # 返回最新值
```

## 技术细节

### 算法复杂度
- **时间复杂度**：O(n)，其中n是柱数
- **空间复杂度**：O(n)，用于存储轨道数组

### 关键实现细节

1. **ATR计算**：使用 `min_periods=1` 避免初始NaN值
2. **曲率加速**：基于ATR的二次加速，确保波动率调整
3. **平滑处理**：可选的SMA平滑以减少噪音
4. **趋势检测**：通过价格与轨道交叉的稳健逻辑
