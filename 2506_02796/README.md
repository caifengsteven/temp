# LSTM-BEKK Trading System

A comprehensive implementation of the LSTM-BEKK model for multivariate volatility modeling and algorithmic trading, based on the research paper "Deep Learning Enhanced Multivariate GARCH".

## 🎯 Overview

This system combines the econometric rigor of BEKK (Baba, Engle, Kraft, and Kroner) models with the adaptive capabilities of LSTM neural networks to create a sophisticated trading framework for portfolio optimization and risk management.

### Key Features

- **Hybrid LSTM-BEKK Model**: Combines traditional econometric models with deep learning
- **Multiple Trading Strategies**: GMV portfolio optimization, volatility-based sizing, correlation breakdown detection
- **Comprehensive Risk Management**: VaR, Expected Shortfall, stress testing, and real-time monitoring
- **Advanced Backtesting**: Walk-forward analysis with benchmark comparisons
- **Interactive Dashboard**: Real-time monitoring and visualization
- **Production-Ready**: Proper logging, error handling, and configuration management

## 📊 Model Architecture

The LSTM-BEKK model implements the following equation:

```
H_t = CC' + C_t*C_t' + a*r_{t-1}*r_{t-1}' + b*H_{t-1}
```

Where:
- `H_t`: Conditional covariance matrix at time t
- `CC'`: Static covariance component
- `C_t*C_t'`: Dynamic component generated by LSTM
- `a, b`: BEKK parameters for shock and persistence effects

1. Clone the repository:
```bash

```

2. Install dependencies:
```bash
pip install -r requirements.txt
```

3. Configure the system:

#### Run Backtest
```bash
python main.py --mode backtest --universe sp500_sample
```

#### Launch Dashboard
```bash
python main.py --mode dashboard --results backtest_results.pkl
```

#### Live Trading Simulation
```bash
python main.py --mode live --universe sp500_sample
```

## 📈 Trading Strategies

### 1. Global Minimum Variance (GMV) Portfolio
- Minimizes portfolio variance using LSTM-BEKK covariance forecasts
- Implements position size constraints and turnover limits
- Supports both long-only and long-short strategies

### 2. Volatility-Based Position Sizing
- Adjusts position sizes based on predicted volatility levels
- Targets specific volatility levels for risk control
- Implements dynamic rebalancing triggers

### 3. Correlation Breakdown Detection
- Identifies when asset correlations deviate from model predictions
- Generates trading signals based on correlation regime changes
- Supports pairs trading strategies

### 4. Dynamic Portfolio Rebalancing
- Rebalances portfolios based on changing covariance forecasts
- Implements transaction cost considerations
- Supports multiple rebalancing frequencies

## 🔧 Configuration

The system is configured through `config.yaml`:

```yaml
# Data Configuration
data:
  bloomberg:
    start_date: "2019-01-01"
    end_date: "2024-01-01"
  universes:
    sp500_sample: ["AAPL US Equity", "MSFT US Equity", ...]

# Model Configuration
model:
  lstm_bekk:
    hidden_size: 64
    num_layers: 3
    dropout: 0.2
    learning_rate: 0.001

# Trading Configuration
trading:
  portfolio:
    initial_capital: 1000000
    max_position_size: 0.1
    rebalance_frequency: 5
  risk:
    max_portfolio_volatility: 0.15
    var_confidence: 0.05
```

## 📊 Performance Metrics

The system calculates comprehensive performance metrics:

- **Return Metrics**: Total return, annualized return, Sharpe ratio
- **Risk Metrics**: Volatility, maximum drawdown, VaR, Expected Shortfall
- **Risk-Adjusted**: Calmar ratio, Sortino ratio, Information ratio
- **Tail Risk**: Value-at-Risk, Expected Shortfall at multiple confidence levels
